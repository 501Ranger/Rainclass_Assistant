# 长江雨课堂自动助手

这是一个用于长江雨课堂的自动化工具，旨在帮助学生自动完成随堂测试和签到。该工具通过模拟浏览器操作，结合AI模型（豆包AI或Gemini AI）自动识别题目并给出答案，同时支持微信通知提醒。

## 功能特性

- **自动签到**: 自动检测并完成课堂签到任务。
- **自动答题**: 自动识别随堂测试题目（支持客观题和主观题），并利用AI模型给出答案。
- **AI模型支持**: 集成豆包AI和Gemini AI，可根据用户配置选择使用。
- **静默运行**: 支持无头模式（headless mode），可在后台静默运行，不显示浏览器界面。
- **Cookies管理**: 自动获取和保存登录Cookies，并提供Cookies有效期提醒。
- **微信通知**: 通过xxtui平台发送微信通知，及时提醒用户签到、答题情况及Cookies过期预警。
- **可配置时间段**: 用户可设置每日自动检查课程的开始和结束时间。
- **自定义ChromeDriver路径**: 支持指定本地ChromeDriver路径，也可自动下载。
- **日志记录**: 详细的日志输出，方便用户追踪程序运行状态。
- **图形用户界面 (GUI)**: 提供直观的Tkinter界面，方便用户进行设置和操作。

## 安装与运行

### 1. 克隆仓库

```bash
git clone https://github.com/501Ranger/Rainclass_Assistant.git
cd Rainclass_Assistant
```

### 2. 安装依赖

确保您的系统已安装 Python 3。然后安装所需的 Python 库：

```bash
pip install -r requirements.txt
```

**注意**: `requirements.txt` 文件需要您手动创建，并包含以下内容：

```
selenium
webdriver-manager
requests
openai
Pillow
```

### 3. 配置 ChromeDriver

本工具会自动尝试下载并安装与您当前Chrome浏览器版本兼容的ChromeDriver。如果您遇到问题，或者希望使用本地已有的ChromeDriver，可以在设置中指定其路径。

### 4. 配置 AI API Key 和微信提醒

在首次运行程序后，会在项目根目录生成 `config.json` 文件。您也可以通过图形界面在“设置”页面进行配置：

- **AI模型选择**: 选择“豆包AI”或“Gemini AI”。
- **豆包AI API Key / Gemini AI API Key**: 填写您选择的AI模型的API Key。
- **微信提醒API Key**: 填写您的xxtui API Key，用于接收微信通知。

### 5. 获取登录 Cookies

在“设置”页面点击“获取登录Cookies”按钮。程序将启动一个浏览器窗口，请在该窗口中完成长江雨课堂的登录。登录成功后，Cookies将自动保存，并用于后续的自动化操作。

### 6. 运行程序

```bash
python main.py
```

程序将启动一个图形界面。在“主页”点击“启动自动答题”即可开始自动化任务。

## 使用说明

1. **首次运行**: 
   - 运行 `python main.py` 启动程序。
   - 切换到“设置”页面。
   - 配置您的AI API Key和微信提醒API Key。
   - 点击“获取登录Cookies”并完成登录。
   - 保存设置。
2. **启动/停止**: 在“主页”点击“启动自动答题”或“停止自动答题”按钮来控制程序的运行。
3. **监控日志**: 在“主页”的日志区域可以实时查看程序的运行状态和操作记录。
4. **Cookies有效期**: 程序会显示Cookies的有效期，并在即将过期时通过微信提醒您。请及时更新Cookies以确保程序正常运行。

## 注意事项

- 请确保您的网络连接稳定。
- 请勿在程序运行期间手动操作浏览器窗口，以免干扰自动化流程。
- AI模型的回答准确性受多种因素影响，包括图片清晰度、题目复杂度和模型能力。对于重要考试或作业，请务必人工复核。
- 本工具仅供学习和研究使用，请遵守相关平台的使用协议。
